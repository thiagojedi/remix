# Frames Demo (Deno version)

Same as the Frames Demo, but running on Deno toolchain.

## Running this demo:

Assuming `deno` already installed on the system:

- For dev server, run: `deno task dev`

- For prod server, run: `deno task start` or `deno task start:fetch`.

Run `deno task` or read `deno.json` for details of the tasks.
